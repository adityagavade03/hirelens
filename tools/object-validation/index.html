Local object-model comparison

Compare the same photo using Balanced (EfficientDet-Lite0) and More detail (EfficientDet-Lite2). This developer tool uses local model files and browser memory. It does not request camera access, upload images, record an interview, or send interview events.

An example match is not an accuracy validation. For reviewed tests, enter the labels you can actually see before running both models. Include negative examples and varied lighting, cameras, object sizes and angles. Do not use private candidate photos without their consent.

Load a public sample or select a consented local photo. Run npm run setup:assets first.
